How to use the preview

  1. Write a specific title that describes the page.
  2. Explain the page's main value in the description.
  3. Read the preview aloud to check that it sounds natural.
  4. Make sure the title and description match the visible page content.

What character length should I use?

There is no fixed character limit that guarantees a full display. Search snippets are often shortened to fit the available space, which can vary by device and query. Use the counts as writing guidance, not a ranking rule.
