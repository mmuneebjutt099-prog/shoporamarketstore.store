How to Compare Clothing Sizes, Fabrics and Accessories Online

A practical fashion-shopping guide to garment measurements, fabric details, fit, accessory dimensions and product photos.

Shopora Editorial Team · 7 min read

SHOPORA FIELD GUIDEFIT • FABRIC • DETAILS

1. Use measurements, not just size labels

Sizing can vary between brands, garment cuts and countries. When a measurement chart is available, compare it with a similar item you already own that fits comfortably. Check which measurements are listed—such as chest, shoulder, waist, hip, sleeve or garment length—and whether they describe the garment itself or the body it is intended to fit. If the chart does not explain this, ask the seller before ordering.

2. Understand fabric and care details

Fabric composition can affect stretch, breathability, warmth, drape and how an item should be washed. Read the listed materials and care instructions rather than inferring them from the photo. If the listing does not state the fabric or care requirements, treat that as information still to confirm, not a detail to guess.

3. Read photos alongside the description

Photos can help you understand colour, shape and styling, but lighting and screen settings can change how a colour appears. Read the written description for closure type, pockets, lining, included pieces and other practical details. Check the number of items in a set so that accessories used in a photograph are not mistaken for included items.

4. Measure accessories before choosing

For bags, belts, jewellery and other accessories, check dimensions and fastening details. For a bag, compare width, height, depth and strap drop with something you already use. For jewellery, look for length, diameter, material and fastening information where available.

5. Make returns part of the decision

Fit and colour can be difficult to judge online. Review the applicable return policy before ordering and note any conditions that apply to worn, altered or clearance items. Never assume a return is available unless the store's current terms say so.

Quick checklist

  • Compare the size chart with a well-fitting item.
  • Check fabric, material and care details.
  • Confirm which items are included in the package.
  • Check accessory dimensions and fastening details.
  • Read the current return policy before purchase.
