# Shopora article cover assets

Place editorial cover images for the article cards in this folder.

Suggested filenames:
- online-shopping-checklist.webp
- fashion-size-and-material-guide.webp
- electronics-compatibility-checklist.webp
- beauty-product-buying-guide.webp
- home-living-measurement-guide.webp

Use original images created for Shopora or images you have permission to publish. Keep cover images compressed, use descriptive alt text, and do not use product photos that misrepresent the product. The current article cards use a designed CSS cover, so the pages work even before images are added.
